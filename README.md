# BitClient

Торрент-клиент на Python: движок на [libtorrent](https://www.libtorrent.org/) и графический интерфейс на PySide6. Работает на Windows и Linux.

Проект начинался как учебный клиент, написанный с нуля (хранится в папке `legacy/`), а затем получил полноценный движок и интерфейс.

## Возможности

**Загрузки**
- magnet-ссылки и `.torrent` файлы, перетаскивание в окно, вставка из буфера
- выбор файлов внутри торрента, последовательная загрузка
- очередь загрузок и раздач, приоритет в очереди
- перепроверка файлов, обновление анонса трекеров
- проверка свободного места перед добавлением

**Организация**
- категории (у каждой своя папка), метки, фильтр по трекерам
- поиск, сортировка, скрываемые и перемещаемые колонки
- перенос завершённых торрентов в отдельную папку
- наблюдение за папкой: новые `.torrent` подхватываются сами

**Автоматизация**
- RSS-автозагрузка с фильтрами-регулярками
- расписание скоростей и режим ограничения одной кнопкой
- лимиты скорости на весь клиент и на отдельный торрент
- остановка раздачи по рейтингу или времени
- действие после завершения загрузок: сон, выключение, выход

**Сеть**
- привязка к сетевому интерфейсу (например, VPN)
- прокси SOCKS4, SOCKS5, HTTP
- шифрование, блок-лист IP, настройка порта, DHT, LSD, UPnP, NAT-PMP

**Интерфейс**
- тёмная и светлая темы, шрифт Inter, анимации
- трей, уведомления, автозапуск, один экземпляр приложения
- график трафика и статистика за 14 дней
- создание `.torrent` файлов

## Установка и запуск

Нужен Python 3.10 или новее.

```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

На Windows активация окружения: `venv\Scripts\activate`.

Можно сразу открыть торрент или magnet-ссылку:

```
python app.py "magnet:?xt=urn:btih:..."
python app.py file.torrent
```

Консольный режим без интерфейса:

```
python main.py file.torrent "magnet:?xt=..." -o ~/Downloads --seed
```

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Ctrl+O | добавить `.torrent` файлы |
| Ctrl+V | добавить magnet-ссылки из буфера |
| Ctrl+N | создать торрент |
| Ctrl+F | поиск |
| Пробел | пауза / продолжить |
| Delete | удалить из списка |
| Shift+Delete | удалить вместе с файлами |
| Ctrl+, | настройки |
| Ctrl+Q | выход |

## Сборка

```
pip install pyinstaller
python build.py
```

Готовая программа появится в `dist/BitClient/`. Для привязки `.torrent` файлов и magnet-ссылок:

- Linux: `packaging/install_linux.sh`
- Windows: `python packaging/register_windows.py`

При пуше тега вида `v1.0.0` GitHub Actions соберёт версии для Windows и Linux и приложит их к релизу.

## Где хранятся данные

Всё лежит в папке `~/.bitclient/`:

| Файл | Содержимое |
| --- | --- |
| `*.resume`, `meta.json` | состояние торрентов, категории и метки |
| `rss.json` | RSS-ленты и список уже увиденных записей |
| `stats.json` | статистика трафика |
| `log.txt` | лог ошибок (открывается из меню ⚙) |

Настройки интерфейса хранятся в системном хранилище `QSettings`.

## Структура проекта

```
app.py          запуск графического клиента
main.py         консольный клиент
core/           движок без привязки к интерфейсу
  lt_engine.py    обёртка над libtorrent
  schedule.py     расписание скоростей
  rss.py          RSS-автозагрузка
  stats.py        статистика
  maketorrent.py  создание .torrent
gui/            интерфейс на PySide6
assets/         шрифты
packaging/      регистрация в системе
tests/          тесты
legacy/         первый клиент, написанный с нуля
```
